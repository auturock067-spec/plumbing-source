Ball valve

Start with isolation duty. Then specify the connection and operating conditions.

A ball valve is a quarter-turn valve type commonly considered for shut-off duty. Similar-looking bodies can have different port sizes, seats, connections and permitted services. Use this reference to prepare questions; select an actual model against its current manufacturer documents.

Prepare an RFQ checklist →
01 / SPECIFY

What to specify

These are fields to confirm, not supplied model ratings. Exact values depend on the selected product and service.

DutyState whether the requirement is isolation; confirm any control duty with the manufacturer.
ConnectionRecord both ends: standard, nominal size and male/female thread or other joint type.
Wetted materialsRequest exact body, ball, seat and seal materials for the intended medium.
Operating envelopeProvide medium, working pressure and temperature together; ask for the model's applicable rating curve.
Port and operationClarify full/reduced port, handle clearance and any locking requirement.
02 / CHECK

Common mistakes to avoid

  • Comparing nominal size alone while ignoring bore and end connections.
  • Treating a pressure figure as valid at every temperature.
  • Assuming a brass appearance proves alloy grade or drinking-water approval.
03 / ASK

Questions for a manufacturer

  1. Which exact model and drawing match both end connections?
  2. What is the pressure/temperature rating for our stated service?
  3. Which seat and seal materials will be supplied?
  4. Which model-specific documents and spare parts can be provided?

Do not confuse it with…

A ball valve provides manual isolation; a check valve responds to flow direction. They address different requirements and are not direct substitutes.
